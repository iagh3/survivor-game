# DESIGN_BIBLE.md

## Цель

Сделать визуальный стиль игры так, чтобы он выглядел как вручную спроектированный человеческий продукт, а не как типичный AI-generated design.

## Что это значит

Дизайн должен ощущаться:

- продуманным;
- живым;
- осмысленным;
- чуть характерным;
- удобным для игрока;
- не шаблонным.

## Визуальные ориентиры

Используй такие принципы:

- четкая типографическая иерархия;
- ограниченная палитра;
- сильные акценты;
- понятная структура;
- хороший ритм отступов;
- разный визуальный вес элементов;
- аккуратные, но не стерильные формы.

## Запреты

Не использовать:

- одинаковые карточки везде;
- слишком мягкие и одинаково круглые формы;
- обилие glow/blur;
- случайные градиенты;
- пустой корпоративный минимализм;
- визуальную “стерильность”;
- эффект “всё как в шаблоне”.

## Как должен выглядеть интерфейс

Интерфейс должен быть:

- читаемым;
- плотным, но не перегруженным;
- с явным главным элементом;
- с понятными второстепенными блоками;
- с ощущением ручной настройки;
- с характером, а не просто “современно”.

## Правила композиции

1. Главный элемент всегда должен быть очевиден.
2. Второстепенные элементы не должны спорить с главным.
3. Не выравнивай всё до искусственной симметрии.
4. Лучше один сильный акцент, чем пять слабых.
5. Каждый экран должен иметь собственный визуальный ритм.

## Типографика

- Использовать разные размеры и веса шрифта.
- Заголовок должен доминировать.
- Текст подсказок и второстепенная информация должны быть тише.
- Нельзя делать всё одинаково заметным.

## Цвет

- Палитра должна быть ограниченной.
- Один основной акцент.
- Один цвет для опасности/ошибки.
- Один нейтральный фон.
- Избегать декоративных цветов без функции.

## Формы

- Формы должны быть осмысленными.
- Скругления использовать дозированно.
- Не превращать весь интерфейс в “мягкое облако”.
- Важные элементы должны отличаться по форме и весу.

## Эффекты

Можно:

- легкие тени;
- минимальные подсветки;
- умеренные переходы;
- мягкая анимация.

Нельзя:

- чрезмерный glow;
- стеклянный эффект везде;
- heavy blur;
- неон без причины;
- визуальный шум.

## Проверка результата

Перед принятием финального варианта ответь:

- Есть ли характер?
- Это похоже на реальный человеческий дизайн?
- Не выглядит ли это как AI-шаблон?
- Помогает ли стиль игре?
- Есть ли смысл у каждого визуального решения?

Если дизайн выглядит нейросеточно — переделать.
