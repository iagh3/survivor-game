# Mini Survivors

Браузерный top-down авто-шутер в стиле survivors, реализованный в одном HTML-файле без зависимостей. Разработан для публикации на **Яндекс Игры**.

---

## Описание

Mini Survivors — roguelite-шутер в стиле киберпанка. Выбери класс, выживай против волн врагов, собирай реликвии после боссов, прокачивай ДНК-дерево между забегами. Забег длится 3–10 минут; мета-прогрессия — через магазин кредитов и 20-узловое ДНК-дерево.

---

## Геймплей

```
Выбор класса → Старт → Движение + уклонение → Авто-атака
→ Сбор DATA-орбов (XP) → Level up → Выбор 1 из 3 апгрейдов
→ Выживание в surge-волнах → Убийство босса → Выбор реликвии
→ Смерть → Разблокировка DNA-узлов → Следующий забег сильнее
```

## Возможности

### Четыре класса персонажа

| Класс | Пассив | Ультимат |
|-------|--------|----------|
| **ANTIVIRUS** | +12% крит, цепные атаки | Chain Nova — 10 врагов в 320px |
| **FIREWALL** | Пассивная аура урона, overheat ×1.4 | Iron Bunker — 3с иммунитет + аура 180px |
| **SCANNER** | Dash (Space/двойной тап), скорость +25% | Phase Burst — AoE по 5 целям |
| **HACKTIVIST** | +15% крит, скорость атаки | Critical Mass — 5 автокритов ×4 |

### Элитные враги

| Prefix | Поведение |
|--------|-----------|
| HARDENED | Броня-щит 35% HP (cyan полоса), поглощает урон |
| ALPHA | На 50% HP — ярость: скорость ×1.9, цвет меняется |
| OVERCLOCKED | При смерти оставляет ядовитую лужу (10 дмг/с, 5с) |
| CORRUPTED | Телепортируется к игроку каждые 3.5–6 секунд |

### Система реликвий

12 реликвий, предлагается 1 из 3 после каждого убийства босса. Максимум 4 за забег. Примеры: удвоение крит-шанса, лечение от убийств, взрыв при дэше, иммунитет к ядовитым лужам.

### ДНК мета-прогрессия

20 постоянных узлов, разблокируемых за накопленные убийства, боссов, элиток. Бонусы применяются в каждом новом забеге автоматически.

### Прогрессия в забеге

- 30+ пассивных навыков в 5 тирах (red / violet / blue / cyan / green)
- Стеки до 3 на навык с убывающей эффективностью
- Синергии между навыками
- Мета-магазин с постоянными апгрейдами
- XP-мультипликатор от комбо-серии

### Враги и боссы

8 типов обычных врагов + 4 типа элитных (с уникальным поведением) + 6 вариантов MiniBoss с фазой 2 (Enrage при 50% HP).

### 4 локации

| Локация | Условие | Хазард | Сложность |
|---------|---------|--------|-----------|
| Server | Сразу | — | ×1.0 |
| Core | Выжить 3 мин | Огонь каждые 15с | ×1.25 HP/XP |
| Cryo | Level 10 | Заморозка каждые 20с | ×1.5 HP |
| Void | 200 убийств | — | ×1.8 HP/XP |

### Визуал и аудио

- Фоновая музыка (тёмный электронный трек, тихий фон, ON/OFF в настройках)
- Процедурный Web Audio API для звуковых эффектов
- 9 скинов персонажа (разные формы, шлейфы, орбиты)
- 4 процедурных фона (PCB-трассы, огненный клеточный автомат, Voronoi-кристаллы, flow field)
- Система частиц, screen shake, hit-stop, плавающие числа урона/XP

## Запуск

### Локальная разработка

```bash
python3 -m http.server 5500
# Открыть: http://127.0.0.1:5500/index.html
```

SDK Яндекса при отсутствии инициализируется с fallback-симулятором рекламы (3–5 секунд). Игра полностью работоспособна без SDK.

### Публикация на Яндекс Игры

1. Запаковать `index.html` + `track_music.m4a` в ZIP (оба файла в корне, без подпапок)
2. Загрузить в консоль разработчика Яндекс Игр
3. ID лидерборда: `"miniSurvivorsMain"`
4. Язык определяется автоматически из `ysdk.environment.i18n.lang`

## Монетизация

| Механика | Реализация |
|----------|-----------|
| Интерстишиал | После каждой 2-й смерти |
| Rewarded — Возрождение | 50% HP + щит + 3с iframes |
| Rewarded — XP×2 | Следующий забег с двойным XP |
| Rewarded — Буст | 60с: скорость / XP / щит (случайно) — с паузой игры |
| Rewarded — Пропуск DDoS | Первая DDoS волна откладывается |
| GameplayAPI | `start()`/`stop()` для алгоритма рекламы Яндекса |
| Мета-магазин | Кредиты за забег → постоянные апгрейды |
| Скины | Косметика, 80–450 кредитов |
| Daily Challenge | Ежедневные цели, награда в кредитах |
| Лидерборд | Конкурентное удержание через Яндекс |

## Производительность

- Адаптивный DPR: при FPS < 25 снижается до 1x, восстанавливается при FPS > 50
- `_pQuality` (0.35/0.65/1.0): управляет тенями, фоном, туманом
- На мобайле: backdrop-filter и canvas blur отключены
- Caps: 96 вражеских снарядов, 80 снарядов игрока
- CSS: `will-change` на анимированных элементах, safe-area поддержка
