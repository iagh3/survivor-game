# Mini Survivors

Браузерный top-down авто-шутер в стиле survivors, реализованный в одном HTML-файле без зависимостей. Разработан для публикации на **Яндекс Игры**.

---

## Описание

Mini Survivors — это survivor-шутер, где вы управляете антивирусным агентом, уничтожающим заражённую сеть. Враги появляются нарастающими волнами; вы собираете XP-орбы, повышаете уровень, выбираете пассивные навыки и строите синергичный «билд», пока не погибнете. Забег длится 3–10 минут, после — мета-прогрессия через магазин кредитов.

---

## Геймплей

```
Спавн → Движение, уклонение → Авто-атака в радиусе
→ Сбор DATA-орбов (XP) → Level up → Выбор 1 из 3 навыков
→ Выживание в surge-волнах и против минибоссов
→ Смерть → Трата кредитов в магазине → Следующий забег сильнее
```

- Продолжительность забега: 3–10 минут
- Сложность растёт через состав волн, surge-вспышки и фазы боссов
- Три класса персонажа с уникальными механиками
- Биомы меняются каждые 45 секунд (атмосфера + сетка фона)

---

## Возможности

### Основной геймплей

- Авто-атака в радиусе с настраиваемым диапазоном и скоростью
- 8 типов врагов с уникальным поведением
- 6 вариантов минибоссов с фазой 2 (Enrage при 50% HP)
- Surge-волны: 7-секундные вспышки плотного спавна каждые 45 сек после первой минуты
- Граница мира (r=1200) с видимым кольцом узлов и туманом

### Классы персонажа

| Класс         | Уникальная механика                          |
| ------------- | -------------------------------------------- |
| **ANTIVIRUS** | +12% базовый крит, цепные атаки со старта    |
| **FIREWALL**  | Пассивная аура урона, overheat capacity ×1.4 |
| **SCANNER**   | Dash по Space (КД 3.5с, неуязвимость 0.55с)  |

### Прогрессия

- 15 пассивных навыков в 5 тирах (red / violet / blue / cyan / green)
- Стеки до 3 на навык, убывающая эффективность: 100% / 65% / 40%
- 4 синергии: Vampire Core, Iron Berserker, Railgun Mode, Phase Runner
- XP-мультипликатор от комбо-серии
- Мета-магазин с 9 постоянными апгрейдами

### Боссы

| Имя       | Поведение                                     |
| --------- | --------------------------------------------- |
| PULSAR    | Медленное сближение, кольцо из 8→12 снарядов  |
| BERSERKER | Рывок ×5.5→7.5, урон при контакте             |
| SUMMONER  | Держит дистанцию, спавнит миньонов            |
| SNIPER    | Прицельный залп 1→3 снаряда в веере           |
| VORTEX    | Кружит вокруг игрока, непрерывный огонь       |
| GHOST     | Телепортируется каждые 2.2→1.4с, взрыв-кольцо |

### Визуал и аудио

- Процедурный Web Audio API — внешних звуковых файлов нет
- Система частиц, screen shake, hit-stop, плавающие числа урона/XP
- 6 скинов персонажа (разные формы и типы шлейфа), покупаются за кредиты
- 3 биома, циклично сменяющихся каждые 45 секунд
- SVG-иконки в карточках апгрейдов с glow-эффектом

### Платформа

- **Яндекс Игры SDK v2**: rewarded-реклама (возрождение, XP×2, буст скорости), интерстишиалы, лидерборд
- **Daily Challenge**: 3 случайные цели в день с наградой в кредитах
- **localStorage**: история забегов, мета-прогресс, ежедневные рекорды
- Полная локализация RU / EN

### Адаптивность

- 7 брейкпоинтов (320px → 1920px)
- Touch-джойстик для мобайла
- Поддержка safe-area (вырезы камеры)
- HiDPI/Retina масштабирование canvas

## Запуск

### Локальная разработка

```bash
# Любой статический сервер. Пример с Python:
python3 -m http.server 5500
# Открыть: http://127.0.0.1:5500/index.html
```

SDK Яндекса при отсутствии инициализируется с fallback-симулятором рекламы (3–5 секунд). Игра полностью работоспособна без SDK.

### Публикация на Яндекс Игры

1. Запаковать `index.html` в ZIP (один файл, без подпапок)
2. Загрузить в консоль разработчика Яндекс Игр
3. В настройках SDK указать ID лидерборда: `"miniSurvivorsMain"`
4. Проверить через Яндекс Preview Tool — SDK инициализируется автоматически

## Известные проблемы

1. **Биомы только визуальные** — фон и сетка меняются, игровых эффектов (замедление в Ice, буст в Core) пока нет
2. **Dash Scanner недоступен на мобайле** — Space не замаплен на тач-событие
3. **Прогресс Daily Challenge не отображается в матче** — цели проверяются только при смерти
4. **Регулятора громкости нет** — аудио включено/выключено только через браузер
5. **Экрана достижений нет** — achievements сохраняются в localStorage, но не показываются игроку
6. **Снаряды игрока визуальные** — урон наносится мгновенно при атаке; `playerBullets` не имеют коллизии
7. **Просадка FPS на слабых устройствах** при 55+ врагах + снаряды Gunner + частицы — автоматического снижения качества нет
